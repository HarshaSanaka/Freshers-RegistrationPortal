# Fresher Registration Portal

## Project Description

A web-based platform that allows newly admitted
students to register and submit their basic
information through self-registration or college
provided credentials.

## Features

- Student registration
- College credential login
- Student dashboard
- Personal information
- Academic information
- Document upload
- Admin verification
- Registration status

## Technologies

Frontend:
HTML,CSS,JavaScript,BootSrap

Backend:
Python+Django

Database:
SqlLite

Version Control:
Git + GitHub
